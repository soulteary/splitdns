# splitdns v1.1.3

Release date: 2026-11-26 (Asia/Shanghai).

Rebuild the macOS CLI with Go 1.27.4 and the current pflag dependency. Resolver configuration syntax and command behavior are unchanged. Validate dry-run and isolated-directory apply/remove behavior before using privileged operations; release preparation does not modify host DNS settings.

## Upgrade and rollback

Retain the previous exact program/image and back up configuration before rollout. Stop affected writers during replacement; validate the actual configured user path in staging. Restore the complete previous dependency lockfiles when rebuilding an older source version.

Full changes: https://github.com/soulteary/splitdns/compare/v1.1.2...v1.1.3

## Test reliability

Use a local non-answering UDP socket for the DNS timeout regression and assert the timeout error type; external DNS interception no longer controls the test result. Native macOS race tests passed after the correction.
